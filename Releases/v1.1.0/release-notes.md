# AutoHDR v1.1.0

## Co nowego

- Automatyczne wykrywanie gier z **Microsoft Store / Xbox Game Pass**.
- Nowy plik `store_game_publishers.txt` — biała lista wydawców ze Store, którą można samodzielnie rozbudowywać.
- Dodatkowe filtrowanie paczek systemowych i narzędzi Microsoftu, aby zmniejszyć liczbę fałszywych alarmów.
- Poprawione wczytywanie nazw procesów ze spacjami, nawiasami i innymi dozwolonymi znakami.
- Usunięto dymki powiadomień przy odświeżaniu listy gier.

## Pliki

- `AutoHDR-1.1.0.msi` — instalator Windows
- `AutoHDR-1.1.0-portable.zip` — wersja przenośna

## Wymagania

- Windows 10 lub Windows 11
- .NET Framework 4.8

# AutoHDR v1.0.0

Pierwsza publiczna wersja AutoHDR.

## Co nowego

- Automatyczne włączanie HDR po uruchomieniu gry.
- Przywracanie stanu HDR po zamknięciu ostatniej gry.
- Wykrywanie gier z bibliotek: Steam, Epic Games, GOG, EA App, Ubisoft Connect, Battle.net.
- Wbudowana lista 800+ znanych gier.
- Okno edycji listy gier (dodawanie własnych `.exe`).
- Autostart z Windows.
- Instalator MSI i wersja przenośna.
- Dwujęzyczny interfejs (polski / angielski).
- Własna ikona aplikacji i logo.
- Obsługa nowego API `DISPLAYCONFIG_SET_HDR_STATE` na Windows 11 24H2+ (build 26100+).

## Pliki

- `AutoHDR-1.0.0.msi` — instalator Windows
- `AutoHDR-1.0.0-portable.zip` — wersja przenośna

## Wymagania

- Windows 10 lub Windows 11
- .NET Framework 4.8
